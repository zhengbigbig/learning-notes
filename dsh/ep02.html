大家好我是郑同学。EP01 拆完 Cordis 发动机，这一篇看变速箱：五十多个插件包，怎么按需组装成一个能跑的产品。dsh 的答案是一条组装线——profile（配置组装）叠 bundle（组合包），最后用 patch（补丁）层层覆盖。理解了这条线，你就拿到了 dsh 世界的第一件调试工具。

先解决为什么需要组装线。同一个内核要长出浏览器版和命令行一次性版；同一个产品要让用户换掉任何一个部件；这两件事都要求「哪个插件在场」本身是数据而不是代码。dsh 把插件编组做成了三个角色（docs/architecture.zh.md）。

profile 是存放在 Harness home 中的具名组装。它列出自己叠放的组合包、存放树外插件、保存用户自己的 cordis.patch.yml。web 和 headless 两个模板随发行版交付。

bundle 是 Cordis 配置项及其挂载代码的分发格式。它在自己的 package.json 里用 dsh 字段自我声明：dsh.profile 列 profile 的组合包清单，dsh.bundle 指向组合包的 patch 文件。

patch 是最小编辑单元。一条 patch 按 id 定位某个条目并替换它的整个 config，或插入新条目。

层叠顺序：四层，后写胜出

组装不是随便叠。架构文档写死了顺序（docs/architecture.zh.md）：

先按 profile 列出的顺序应用每个组合包
然后是 profile 的 cordis.patch.yml
然后是 home 级的那一份
最后是任意 --patch overlay
 

四层依次应用到空条目列表上，同行 id 后写胜出（last write wins）。dsh-base 是每个 profile 的第一层：模型适配器、工具、持久化、沙箱与审批策略、设置、凭据、遥测都在里面。dsh-web-app 往上叠浏览器应用；dsh-headless 叠一次性运行器。

有个容易踩的细节要划重点：patch 替换的是目标行的整个 config，不存在深度合并层（base README 已知限制第一条）。你在自己 patch 里改了某行的一个字段，必须把该行需要保留的其他字段全部重述一遍——漏了哪个，哪个就没了。这是这条组装线最锋利也最容易伤手的地方。

一个值得单独讲的门控设计：shell 执行栈有两套孪生行，bash 和 pwsh，同一份 patch 文件里按平台二选一：

- id: bash-sandbox
  name: '@deepseek-ai/dsh-bash-sandbox'
  disabled: !!js process.platform === 'win32'
  config:
    timeoutMs: 60000
 
- id: pwsh-sandbox
  name: '@deepseek-ai/dsh-pwsh-sandbox'
  disabled: !!js process.platform !== 'win32'
 

!!js 把表达式解析为惰性节点，每个宿主恰好挂载一个 shell 栈，权限面在两个平台完全一致。base README 还写明了恢复配方：Windows 上想要 bash 回来，必须禁用 pwsh 两行、重新启用 bash 两行——配方不完整会在加载时直接报错，因为两个执行器家族注册同一个 bash 服务。宁可启动失败，不可静默半装。

顺带一提沙箱的默认值就在这几行里：DSH_PERMISSION_MODE 环境变量缺省时，sandbox-policy 取 workspace-write，approval 策略取 ask——只有显式切到 danger-full-access 才变成 never。安全默认值是组装线上的数据，不是文档里的建议。

你的第一件调试工具

这条组装线配了一个官方透视镜：

dsh --profile web --dump-config
 

它打印你的机器实际启动的完整配置树。任何一层 patch 的效果、任何一行的最终 config、平台门控后哪行被禁用，全在这一份输出里。文档的原话很有底气：它打印出的任何条目，都可以由你自己的 patch 替换。

排查「为什么我的插件没生效」的标准流程就是：dump 配置树 → 找到目标行 → 看它的 config 是不是被上层 patch 整行换掉了。EP09 动手篇会实际用到这个流程。

小结

角色是什么关键规则
profile具名组装列 bundle 清单，存用户 patch
bundle分发格式package.json 的 dsh 字段自声明
patch最小编辑按 id 定位，整行替换不合并
层叠四层顺序bundle→profile→home→overlay，后写胜出

口诀：四层叠加，后写为王；一行一命，改需重述。
